# Abhinav Patidar — Portfolio

Next.js 16 · React 19 · Tailwind 4 · Framer Motion. Light theme by default with a dark toggle.

```bash
npm run dev     # http://localhost:3000
npm run build
```

All content lives in `data/`:

- `profile.ts` — name, links, headline, about/journey text, process steps, stats, experience bullets
- `products.ts` — ESTIMO (flagship), Synthia / ParkBuddy, unified platform, other systems, Estimo modules and flow
- `stack.ts` — marquee items and the three skill groups
